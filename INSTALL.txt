Master Order Helper 1.27

The install files are at the ZIP's top level. In the Lovely Runner GitHub Pages root (the same folder as index.html and style.css):
- Replace master-order-delivery.html
- Replace master-order-delivery.js
- Keep ae-order-form-template.xlsx in this folder for A+E Media Resources orders
- Keep per-second-order-template.xlsx in this folder for generic Per Second orders

Do not upload these files inside a new subfolder. Commit and push the four app files, then hard-refresh the Master Order Helper page. The page displays version 1.27 and loads the script with the 1.27 cache key.

Per Second screener capture now measures actual source seek and frame-callback timing for each selected video. When a source file has a slow seek or delayed frame callback, the helper switches that file to a faster path: it waits for the browser's completed seek, waits for the frame to paint, and verifies the requested time and ready state before drawing. The reference cut workflow and order-specific templates are unchanged. Source Out fallback at Source In plus EDL Source Duration remains available if its direct timecode seek fails.
