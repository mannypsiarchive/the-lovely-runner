The Shot Review includes a live Capture Activity panel and a Download Timing Report button. The report separates file load, seek, frame capture, OCR model load, OCR work, shot preparation, and workbook build time. It contains anonymized labels such as “Screener 1,” file size/type, timing values, and browser user-agent only. It does not include video, screenshots, source filenames, timecodes, spreadsheet values, or Google credentials. The report is downloaded locally; it is not sent anywhere automatically.
