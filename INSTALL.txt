Master Order Helper 1.31

Install the files in the ZIP's top level into the Lovely Runner GitHub Pages root (the same folder as index.html and style.css):
- Replace master-order-delivery.html
- Replace master-order-delivery.js
- Keep ae-order-form-template.xlsx for A+E Media Resources orders
- Keep per-second-order-template.xlsx for generic Per Second orders
- Keep fox-order-form-template.xlsx for Fox News Archive / FOX Archives Per Second orders

Do not upload the files inside a new subfolder. Commit and push the app files and all three templates, then hard-refresh the Master Order Helper page. The page displays version 1.31 and loads the script with the 1.31 cache key.

FOX Archives orders use a separate order form and review setup. The form is based on the supplied FOX order template. Company names, company details, production details, license fields, and the government-agency answer can be entered before review. Each reviewed shot writes its original file name, confirmed burned-in timecodes, exact EDL duration text, and chosen or typed description. The FOX Entity column remains blank. The Source In frame is embedded in column L for reference.

The A+E and generic Per Second templates and order flows remain separate from the FOX template.
