Master Order Helper 1.22

The install files are at the ZIP's top level. In the Lovely Runner GitHub Pages root (the same folder as index.html and style.css):
- Replace master-order-delivery.html
- Replace master-order-delivery.js
- Keep ae-order-form-template.xlsx in this folder for A+E Media Resources orders
- Keep per-second-order-template.xlsx in this folder for other Per Second orders

Do not upload these files inside a new subfolder. Commit and push the four app files, then hard-refresh the Master Order Helper page. The page displays version 1.22 and loads the script with the 1.22 cache key.

Per Second reviews run one source at a time. Confirm every shot and download that source's order form before choosing the next source and selecting Start Next Review. The cut file, screener folder, tracker rows, and detected media metadata remain loaded between reviews.
