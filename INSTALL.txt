Master Order Helper 1.30

The install files are at the ZIP's top level. In the Lovely Runner GitHub Pages root (the same folder as index.html and style.css):
- Replace master-order-delivery.html
- Replace master-order-delivery.js
- Keep ae-order-form-template.xlsx in this folder for A+E Media Resources orders
- Keep per-second-order-template.xlsx in this folder for generic Per Second orders

Do not upload these files inside a new subfolder. Commit and push the four app files, then hard-refresh the Master Order Helper page. The page displays version 1.30 and loads the script with the 1.30 cache key.

Per Second screener metadata now keeps a detected frame rate even when the container has no embedded start timecode. If the EDL source timecode maps inside that screener's duration, the helper captures it as a clip-relative position and shows a visible note for manual verification against the burned-in timecode. This MediaInfo path reads file metadata in slices and does not require loading a large screener into an FFmpeg memory buffer just because its start-timecode tag is absent. Reference-cut metadata requirements, order templates, and OCR behavior are unchanged. The live Capture Activity panel and local Timing Report from 1.29 remain included.
