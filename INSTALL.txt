Master Order Helper 1.23

The install files are at the ZIP's top level. In the Lovely Runner GitHub Pages root (the same folder as index.html and style.css):
- Replace master-order-delivery.html
- Replace master-order-delivery.js
- Keep ae-order-form-template.xlsx in this folder for A+E Media Resources orders
- Replace per-second-order-template.xlsx with the included template for generic Per Second orders

Do not upload these files inside a new subfolder. Commit and push the four app files, then hard-refresh the Master Order Helper page. The page displays version 1.23 and loads the script with the 1.23 cache key.

After confirming and downloading an order form, select Reset Per Second Order Feature to clear that review and start another source. The reset preserves the loaded tracker rows, reference cut, raw screener folder, and detected media metadata.
