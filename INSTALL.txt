Master Order Helper 1.25

The install files are at the ZIP's top level. In the Lovely Runner GitHub Pages root (the same folder as index.html and style.css):
- Replace master-order-delivery.html
- Replace master-order-delivery.js
- Keep ae-order-form-template.xlsx in this folder for A+E Media Resources orders
- Keep per-second-order-template.xlsx in this folder for generic Per Second orders

Do not upload these files inside a new subfolder. Commit and push the four app files, then hard-refresh the Master Order Helper page. The page displays version 1.25 and loads the script with the 1.25 cache key.

Source-frame capture uses embedded start timecode whenever it maps inside the screener. If that mapping falls outside the clip but the EDL timecode maps to a valid clip-relative frame, the helper captures from that position and displays a visible alignment warning for manual verification. Reference-cut timing and previously valid source mappings are unchanged.
